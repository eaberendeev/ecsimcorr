# ECSIM с формами Whitney

Выбор: `"Scheme": "ecsim_whitney"` в JSON либо
`Scheme_name = "ecsim_whitney"` в исходном Python-конфиге.
Требуются не менее четырёх ячеек на ось и прямоугольный домен без damping.
Периодические оси поддерживаются; на непериодических разрешены только
поглощающие грани `open`/`ER0`. Точечная схема удаляет пересекшую частицу до
сборки отклика, а `ballistic` обрезает её траекторию и сохраняет усечённый
ток. Сохраняется ограничение обычного `update_cells`: за шаг частица
перемещается только в соседнюю ячейку.

## Пространственное ядро

В соседней симплектической реализации
`simplectic/srcBeren/simulation/symplectic/whitney_pic.cpp` используются
низшие формы Whitney на Yee-сетке. Для скалярной плотности это CIC:
`S1(x) S1(y) S1(z)`. Для `Ex/Jx` — `S0(x) S1(y) S1(z)`, а для `Bx` —
`S1(x) S0(y) S0(z)`; остальные компоненты получаются перестановкой осей.
`S0` постоянно внутри ячейки; `S1` — линейная шапка на узлах.
На плоскости ячейки выбирается ячейка справа (`floor`).

Полностью неявная ECCAPFIM в соседней ветке использует родственную
конструкцию более высокого порядка: квадратичную плотность и пониженный
порядок вдоль компоненты тока, с общими весами gather/scatter вдоль орбиты.
Здесь реализован именно низший вариант из симплектического метода.

## Шаг и энергетическое сопряжение

Временные уровни остаются уровнями обычного ECSIM:

1. `x^{n-1/2} -> x^{n+1/2} = x^{n-1/2} + dt v^n` и периодический перенос.
2. Gather `B^n+BInit` формами граней в `x^{n+1/2}`. Для
   `b = q dt B/(2m)` определить
   `alpha u = (u + u cross b + b (u dot b))/(1+b^2)`.
3. Собрать `Jp = sum q w W^T alpha v^n` и
   `L = sum (dt^2 q^2 w/(4m)) W^T alpha W`, где `W` — gather по рёбрам.
4. Обычный решатель ECSIM находит `Ebar=E^{n+1/2}`, включая прежний член
   `-L E_external` в RHS.
5. Boris с теми же `W` и магнитным gather вычисляет `v^{n+1}`.
   Сохранить диагностический ток `sum q w W^T (v^n+v^{n+1})/2`.
6. Обычное обновление `E^{n+1}=2 Ebar-E^n` и Faraday для `B^{n+1}`.

Следовательно, `Jbar = Jp + (2/dt) L (Ebar+E_external)` и
`delta K = dt <Ebar+E_external, Jbar>` с обычной нормировкой Beren.
Нельзя заменить только gather, оставив старые Jp/L: это нарушит сопряжение.
Скалярная плотность в диагностике остаётся Linear и согласована с CIC.

Периодические депозиты сразу суммируются на уникальных физических узлах.
Затем копируются alias-узлы; повторный `apply_to_fields(CURRENT)` недопустим.
Строки L копируются на alias-узлы, столбцы указывают на физические DOF.
По умолчанию используется последовательный эталон (`"WhitneyAssembly":
"reference"`). Опция `"WhitneyAssembly": "cell"` включает OpenMP для
сборки отклика по ячейкам и толчка скоростей. Матрица по-прежнему
накапливается блоками 12x12 и собирается Eigen из triplets. Общие токи
сначала накапливаются в отдельных полевых буферах потоков, затем складываются
после барьера; дополнительная память пропорциональна числу потоков и узлов.
Электрические веса в толчке вычисляются один раз для gather и scatter.
Старые ядра и схемы не изменены.

## Что означает сохранение заряда

Whitney gather коммутирует с градиентом CIC-потенциала. Интеграл этих
весов вдоль фактической траектории даёт ток, удовлетворяющий непрерывности
для CIC-плотности. Это проверяется независимо, включая пересечение ячейки
и периодической границы.

В базовой `ecsim_whitney` используется точечный отклик ECSIM, а дрейф идёт с
`v^n`, тогда как ток поля связан с `(v^n+v^{n+1})/2`. Поэтому **точная
непрерывность заряда и сохранение невязки Гаусса там не гарантируются**.

## Проверки и короткое сравнение

```bash
cmake -S srcBeren -B /tmp/beren-whitney -DBUILD_TESTS=ON -DCMAKE_BUILD_TYPE=Release -DUSE_TIMERS=ON
cmake --build /tmp/beren-whitney --target run_ecsim_whitney -j 4
```

Тест проверяет независимую тензорную форму, постоянные поля, градиент,
непрерывность интегрированного тока, совпадение Jp/L с Boris-током при
неоднородных B и E_external, работу поля и сохранение полной энергии.
NaN/Inf означают отказ.

Тот же тест сравнивает точечные и замороженные схемы на одинаковых частицах (фиксированный seed):
4x4x4 ячейки с `h=(0.8,1.1,1.3)`, по 8 частиц каждого сорта в ячейке,
заряды ±1, массы 1 и 25, нулевое начальное B, `dt=0.1`, 20 шагов.
Начальное E одинаково для обеих схем: периодическое решение Пуассона
обеспечивает `div E = rho` с точностью округления. Скорости имеют нулевое
среднее распределения и стандартное отклонение `0.12/sqrt(m)`.
CSV находится в `<build>/test_results/ecsim_whitney/ecsim_whitney_comparison.csv`.
`electric_rms` — RMS всех компонент E, служит прокси полевых флуктуаций,
но не отделяет физические моды от численного шума.
`gauss_rms` — RMS `div E^{n+1}-rho(x^{n+1/2})` по физическим узлам;
`gauss_drift_rms` вычитает начальный дефект. Это обычное временное
рассогласование ECSIM, одинаковое для обеих схем.
`energy_error` — отклонение полной энергии от начальной.
Уменьшение этих метрик не является условием прохождения теста: гипотеза
о снижении шума требует дальнейшей статистики и разрешения по сетке/времени.

В коротком Release-запуске с двумя потоками для случая `dt01` на шаге 20 получено:

| Метрика | ECSIM | ECSIM Whitney |
| --- | ---: | ---: |
| RMS дефекта Гаусса | 0.0470451 | 0.00755204 |
| RMS компонент E | 0.0281095 | 0.0241047 |
| Изменение полной энергии | 9.63e-11 | 1.31e-12 |

Таким образом, в этом опыте дефект Гаусса меньше примерно в 6.2 раза.
Разница RMS поля не доказывает снижение численного шума: меняется также
отклик плазмы. Один короткий опыт не устанавливает преимущества для других
режимов. В отдельном пробном запуске с начальным E=0 полевые флуктуации
Whitney были выше, хотя дрейф дефекта Гаусса был меньше.

## Замороженная траектория

Точечная схема сохранена. Отдельный вариант включается так:

```json
{
  "Scheme": "ecsim_whitney_frozen",
  "WhitneyOrbit": {"predictor": "ballistic"}
}
```

`WhitneyOrbit` необязателен, по умолчанию выбран `ballistic`. Ограничения
домена те же, что выше; непериодические поглощающие стенки разрешены для
`ballistic` (отражение — только для совместимых
сценариев с поверхностным зарядом). Предиктор определяет только геометрию
интегрального ядра. Фактические координаты по-прежнему дрейфуют как в ECSIM:
`x_a=x^{n-1/2}`, `x_b=x_a+dt*v^n`. Пробные скорости не записываются в частицы.

Доступны четыре предиктора (`a=x_a`, `v=v^n`, `h=dt/2`):

| predictor | Замороженный путь |
| --- | --- |
| `ballistic` | Прямая `a -> a+dt*v`; совпадает с фактическим дрейфом координат. |
| `old_fields` | Пробный полный Boris в `E^n+E_external`, `B^n+BInit`, собранных в `a`; прямая к `a+h*(v+v_trial)`. |
| `half_drift` | Полшага `a -> m=a+h*v`; пробный полный Boris в старых полях, собранных в `m`; второе полушаговое звено `m -> m+h*v_trial`. |
| `centered_fields` | Старые поля собираются в `a+h*v`; от `v^n` выполняются пробные Boris на `-dt/4` и `+dt/4`. Два звена по `h` используют полученные скорости. |

Это явные предикторы, не точное решение движения в неоднородных старых
полях. `v^n` находится в середине интервала координат ECSIM. Поэтому
`old_fields` и `half_drift` рассматриваются как геометрические гипотезы,
а не как приближения второго порядка для этой расстановки временных уровней.
`centered_fields` учитывает такое расположение скорости: при однородном E
он даёт баллистический конечный сдвиг и изгиб в середине
`m=a+h*v-dt^2*(q E/mass)/8`. Это свойство проверяется аналитически.

Для прямой определяется `Wbar = integral_0^1 W(a+s*(b-a)) ds`.
Для двух звеньев это сумма их средних с коэффициентами 1/2 (доли времени,
а не длины). Интегрируются обе формы: электрическая по рёбрам и магнитная
по граням. Путь остаётся развёрнутым через периодические границы; каждый
сегмент делится на плоскостях ячеек. Две точки Гаусса точно интегрируют
квадратичные электрические и линейные магнитные веса в каждой ячейке;
эта реализация сохранена в `assembly=reference`. При `assembly=cell`
используется тот же интеграл в аналитической форме: для двух линейных
множителей с серединными значениями A, B и разностями концов dA, dB
среднее произведение равно `A*B + dA*dB/12`. Магнитные веса линейны,
поэтому достаточно их значения в середине отрезка. Короткая прямая внутри
одной ячейки даёт уникальные индексы и не требует сортировки весов.
Интегратор отклоняет нечисловые координаты, координаты по модулю больше
1e8 ячеек и перемещения больше 1024 ячеек по оси; фактический дрейф всё
равно ограничен соседними ячейками обычного `update_cells`.

До решения поля фиксируются `Wbar` и `Bbar=gather_orbit(B^n+BInit)`.
Затем используются `Jp=sum q*w*Wbar^T*alpha(Bbar)*v^n` и
`L=sum dt^2*q^2*w/(4m)*Wbar^T*alpha(Bbar)*Wbar`.
Это **произведение средних весов**, а не среднее произведения `W^T alpha W`.
После решения применяется Boris с теми же `Wbar` и `Bbar`, поэтому
сохраняются линейность СЛАУ, равенство матричного и фактического токов
и дискретный энергетический баланс.

Веса хранятся в принадлежащем simulation буфере в порядке обхода частиц
после drift/rebin. Между сборкой и толчком частицы не перераспределяются.
Перед новой сборкой и после толчка отклик помечается недействительным;
повторный толчок без сборки отклоняется. Память векторов сохраняется для
следующего шага, но все значения перезаписываются в новом порядке частиц.
Буферы исчезнувших или ставших нейтральными сортов удаляются перед сборкой.
Рабочие векторы интегратора принадлежат потокам и повторно используются
между частицами. Эти буферы не содержат указателей на частицы и не нужны
при restart. Изменение числа частиц при инжекции учитывается до сборки.

При `WhitneyOrbit.assembly=cell` толчок скоростей также выполняется по
ячейкам через OpenMP. Префиксные диапазоны связывают частицы с неизменными
весами отклика; ток работы суммируется из локальных буферов потоков.
Вариант `reference` сохраняет последовательные сборку и толчок.

Ток по-прежнему содержит решённую среднюю скорость `(v^n+v^{n+1})/2`,
которая может отличаться от скорости предсказанного пути. Поэтому даже
при баллистическом предикторе геометрически точный интеграл не даёт точной
непрерывности для фактического движения. Для изломанного пути дополнительно
нужны свои скорости каждого звена в депозите; одна средняя скорость здесь
выбрана ради прежнего энергетического сопряжения ECSIM.

Тест дополнительно сравнивает `dt=0.4, B=0` и `dt=0.4, Bz=2` (случаи
`dt04` и `magnetized_dt04`), везде по 20 шагов. В CSV добавлены `case`,
`predictor` и `continuity_rms`. Последняя метрика — RMS
`(rho_after-rho_before)/dt + div(J_Maxwell)` на физических узлах.
Это независимая локальная невязка, а не только накопленный дефект Гаусса.
В этих опытах источник инжекции отсутствует, E_external=0.
Тесты отклика отдельно включают неоднородные B и ненулевое E_external.

Результат короткого сравнения (RMS дефекта Гаусса после 20 шагов):

| Вариант | dt=0.1, B=0 | dt=0.4, B=0 | dt=0.4, Bz=2 |
| --- | ---: | ---: | ---: |
| ECSIM | 0.047045 | 0.078426 | 0.073036 |
| Точечный Whitney | 0.007552 | 0.026899 | 0.024002 |
| Замороженный ballistic | 0.008020 | 0.046092 | 0.044592 |
| Замороженный old_fields | 0.007978 | 0.044920 | 0.045134 |
| Замороженный half_drift | 0.008001 | 0.045535 | 0.044924 |
| Замороженный centered_fields | 0.008021 | 0.046065 | 0.046174 |

Более сложные предикторы не дают устойчивого преимущества над ballistic.
Он выбран по умолчанию как минимальный контрольный вариант. В этих опытах
накопленный дефект Гаусса точечного Whitney меньше, чем у интегральных
вариантов. При этом локальная невязка непрерывности на последнем шаге для
ballistic против точечного Whitney составляет соответственно
`0.002443/0.012040`, `0.010325/0.026616`, `0.020331/0.025174`.
Меньшая локальная норма сама по себе не гарантирует меньшую накопленную:
знаки, пространственная структура и корреляция ошибок между шагами важны.
Этот опыт не доказывает снижение шума или универсальное превосходство
одного предиктора. Все варианты остаются доступны для дальнейших расчётов.

Формат restart и состояние остаются ECSIM: дополнительных сохраняемых
данных нет; Jp, L и ток работы заново вычисляются на следующем шаге.
Проверка restart с файлами и непериодические границы сюда не входят.
